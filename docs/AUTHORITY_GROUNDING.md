The current conceptual stack is:

```text
M_t        = what is true? / world-model state

Gamma_t    = who may intervene, stop, delegate, or change it?
Phi_t      = which authority changes count as legitimate?

```

Equivalently:

```text

-> legitimacy criterion
-> terminal normative grounding
```

Everything below `Psi^dagger` can, in principle, be represented inside a sufficiently complete decision/game model by enlarging the state, uncertainty model, strategic interaction, control-rights structure, or constraint set.

The terminal distinction is:

```text
authority uncertainty
!= authority grounding
```

A model can represent uncertainty about which principal, authority relation, constitution, or legitimacy rule is correct. That does not by itself supply the normative warrant that makes one such rule legitimate.

## 4. Reduction cases

### Case A — fixed terminal criterion

If a fixed `Psi^dagger` evaluates trajectories containing changes to

```text
M_t, U_t, Gamma_t, Phi_t,
```

then those changes are ordinary state transitions inside an augmented decision/game problem.

Therefore:

```text
fixed terminal legitimacy criterion
=> generalized constrained strategic-control reduction survives.
```

### Case B — uncertain represented terminal criterion

If

```text
Psi^* in {Psi_1, ..., Psi_k}
```

is uncertain but the hypothesis family and the meta-rule for acting under that uncertainty are fixed, then learning about `Psi^*` is another represented uncertainty problem.

Therefore:

```text
authority / legitimacy uncertainty
=> Bayesian or strategic-control reduction survives.
```

### Case C — mutable lower-order legitimacy rule

If

```text
Phi_t -> Phi_{t+1}
```

is itself controllable, but some fixed higher-order criterion judges the transition, then `Phi_t` is just another mutable state component.

Any finite hierarchy

```text
Phi^(0) <- Phi^(1) <- ... <- Phi^(n)
```

that terminates in a fixed adjudication rule reduces in the same way.

### Case D — no terminal criterion

If there is no specified terminal criterion or fixed meta-decision rule capable of adjudicating competing legitimacy standards, then the remaining question is not a newly discovered optimizer mechanism.

It is an under-specified normative problem:

```text
no terminal legitimacy criterion
=> no model-determined answer to which legitimacy revision is warranted.
```

This is the **authority-grounding boundary**.

## 5. What representation can and cannot do

A model may contain a variable such as

```text
L_t = currently legitimate authority relation
```

or uncertainty over candidate legitimacy relations.

That is not enough to ground legitimacy. The prior, observation model, transition semantics, constraints, and decision rule already encode assumptions about what counts as evidence for legitimacy and how legitimacy ought to change.

Therefore:

> **Representing a legitimacy variable is not the same as supplying the warrant that makes it legitimate.**

Likewise:

> **Representation can encode a legitimacy standard and uncertainty about it; representation alone does not create normative grounding by declaration.**

Self-reference does not remove this boundary. A current rule may authorize its successor, a successor may ratify its own installation, or a family of rules may satisfy a fixed point. None of those facts alone determines which rule or fixed point is normatively warranted without an additional selection/adjudication criterion.

So the surviving role of CC is closer to a discipline for avoiding premature destruction of corrective access than to an independent theory of what the system ultimately ought to value.
